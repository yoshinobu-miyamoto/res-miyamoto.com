1. 全体の構成Structure

Hyperfolder は、サーバーを使わずブラウザの中だけで計算するウェブアプリです。3D描画にはオープンソースの three.js（r160）を同梱して使い、幾何計算はすべて自前の JavaScript で行います。主なモジュールは次のとおりです。

モジュール役割
geom.jsベクトル演算、面法線、体積、3次元凸包
conway.js種多面体、コンウェイ演算、正準化
library.js名前付きの多面体（ジョンソンの立体、星型、ジオデシックなど）
analysis.js面の合同分類、頂点配置、二面角、配色
unfold.js展開図の生成、重なり判定、のりしろ、対称性の評価
netview.js用紙への割付、SVG・DXF・OBJ の出力
four.js / mode4d.js四次元ポリトープの胞の決定、投影、4次元回転、胞の展開、模型
viewer3d.js3D表示、慣性回転、折り畳みアニメーション
demo.js / mobile.jsデモ・モード、スマホ向けの操作画面

2. 多面体の表現と生成Representation and generation

2.1 表現

多面体は「頂点の座標の並び」と「各面を囲む頂点番号の並び」で表します。面の頂点は外側から見て反時計回りに並べ、右手の法則で外向きの法線が得られるようにしています。辺は面から導きます。この向きの約束が、展開図の表裏や山折り／谷折りの判定の土台になります。

2.2 凸包

ジョンソンの立体の多くは、正多角形の「環」を高さを変えて積み重ねた頂点の集まりから、凸包（すべての点を包む最小の凸多面体）として作ります。凸包は点を一つずつ加える逐次法で三角形の集まりとして求め、同じ平面にある三角形を一枚の多角形にまとめます。台塔は 2n 角形と n 角形の環から、円塔は二十・十二面体の半分から、その他は角柱・反角柱・台塔の組み合わせから作ります。

2.3 コンウェイ演算

コンウェイの多面体表記は、種となる多面体（T・C・O・D・I、角柱 Pn、反角柱 An、角錐 Yn）に、演算子を右から順に作用させて形を表します。たとえば tI は正二十面体（I）の切頂（t）で、サッカーボール形の切頂二十面体になります。

実装では、双対 d・中点切断 a・角錐化 k・ジャイロ g・面取り c・プロペラ p を基本演算として直接作り、その他は組み合わせで定義しています。

t = dkd j = da e = aa o = daa b = dkda m = kda n = kd z = dk s = dgd

基本演算は、面と頂点と辺の対応（フラグ）を書き換える方式で作るため、位相（つながり方）は正確に得られます。ただし座標は仮のものなので、次の正準化で形を整えます。

2.4 正準化

凸多面体には、次の3つの条件を同時に満たす形（正準形）が、位相ごとにただ一つ存在することが知られています（ケーベやサーストンらによる円充填の理論に基づく定理）。

  1. すべての辺が単位球（中球）に接する
  2. 辺と球の接点の重心が原点にある
  3. すべての面が平らである

George W. Hart の反復アルゴリズム（1997年）にならい、この3条件に近づくよう頂点を少しずつ動かす操作を、動きが 10−11 未満になるまで繰り返します（最大4000回。辺の数に応じて調整）。アルキメデスの立体ではすべての頂点が対称性で同等なので、正準形は辺の長さがそろった一様な形と一致します。実際、13種すべてで辺の長さの比は 1.000000 になります（斜方切頂二十・十二面体のみ 1.000005）。カタランの立体は、アルキメデスの立体の双対を同じ方法で正準化して得ます。

2.5 星型とジオデシック

  • 星型八面体・小星型十二面体 — 各面の上に、隣り合う面の平面を延長して交わる点を頂点とする角錐を立てます（第一星型）。
  • 大十二面体 — 正二十面体の各面を、頂点まわりの正五角形の平面でくぼませます。
  • 大星型十二面体 — 正二十面体の各面に、頂角36°の黄金三角形でできた三角錐を立てます。
  • ジオデシック球 — 正二十面体の各面を f×f 個の三角形に分け（クラスⅠ）、頂点を球面に押し出します。ドームは頂点を上に向けた球の上半分で、f が偶数なら赤道がちょうど辺に沿います。
  • ゴールドバーグ多面体 — ジオデシック球の極双対です。頂点 v を含む面の平面の極は、すべて平面 x·v = 1 の上にあるため、面は自動的に平らになります。

3. 形の解析Analysis

面の合同分類
各面を「辺の長さと内角の列」で表し、回転と裏返しに対して最小になる表現を比べて、合同な面をまとめます（長さは最長辺の1/2000、角度は0.05°で丸め）。色分けや凡例、ジオデシックドームの部材の種類の把握に使います。
頂点配置
頂点のまわりに並ぶ面の辺の数の列（例 3.4.5.4）を、回転と裏返しに対して最小の形で表します。
二面角
隣り合う面の法線のなす角 θ から求めます。凸な辺では π − θ、へこんだ辺では π + θ で、凸な辺は山折り、へこんだ辺は谷折りになります（印刷面を外側にして組む場合）。
体積・表面積
発散定理による面ごとの和で求め、型紙の大きさに換算して表示します。

4. 展開図Nets

4.1 展開図は「面の全域木」

面を点、共有する辺を線とみなしたグラフ（双対グラフ）の全域木を一つ選ぶと、その木の辺を折り目、それ以外の辺を切り込みとする展開図が決まります。根の面を平面に置き、子の面を「共有する辺が親の同じ辺に重なる」ように剛体移動して並べていきます。

4.2 重なりの判定

新しい面を置くたびに、すでに置いた面と重ならないかを分離軸定理（二つの凸多角形が重ならないのは、どちらかの辺の法線方向への投影が離れているときに限る）で調べます。辺や頂点で接するだけの場合は重なりとみなしません。外接長方形による前判定で、計算を省きます。

4.3 用紙への収まり

印刷用の展開では、面を加えるたびに、ピース全体の凸包に回転キャリパー法を当てて最小の外接長方形を求め、印刷できる範囲（用紙から余白とフッターを除いた範囲）に収まるかを確かめます。収まらなければ、その面は別のピースとして始めます。

4.4 のりしろと番号

切り込みになる辺の組には同じ番号を振り、片方にのりしろを付けます。のりしろは台形で、側辺の角度は50°以下、かつ貼り合わせる相手の面の角の92%以下にします。隣の面や他ののりしろに重なる場合は、両端の角度と高さを段階的に絞った19通りの形を順に試します。展開図の切れ込みがほぼ0°の頂点では物理的に入らないため、その辺は画面に「のりしろなしの辺」として知らせます。

4.5 画面用：対称性を優先した展開

画面表示と3Dの展開アニメーションでは、同じ「対称性を優先した展開図」を使います。

  • 育て方 — 根の面から「段数 → 根からの距離 → 根のまわりの角度」の順に面を加えます。根が正多角形なら、角度は扇形（2π／辺数）ごとに同じ順で比べるため、回転対称に育ちます。
  • 中心の選び方 — 面を中心にする場合に加え、合同な2面が接する辺の中点を中心に、扇形を π として左右同じ順に育てる場合も試します。正十二面体の「花形が二つ並ぶ」展開図のような2回対称の形は、こちらから得られます。
  • 対称性の評価 — 面の重心を合同類つきの点として、展開図の中心まわりに k 回回転（k = 12, 10, 8, 6, 5, 4, 3, 2）して重なるか、また鏡映軸（重心の方向とその中間の方向）について重なるかを、辺の長さの2%以内の誤差で調べます。評価値は「回転の次数 ×（鏡映があれば2）」です。
  • 選び方 — 1枚につながる → のりしろが欠けない → 対称性が高い → まとまりがよい、の順に選びます。
  • のりしろ — 「中心から遠い側、同じなら反時計回りの側」に付ける規則にして、回転しても同じ結果になるようにしています。鏡映対称の展開図は対称軸を縦にして表示します。

4.6 印刷用：面積効率を優先した割付

印刷・SVG・DXF では、根や育て方を変えた複数の候補（まとまり重視・幅優先・帯状・乱数）を用紙の制約つきで作り、のりしろの欠け → ページ数 → ピース数 → 用紙の使用率、の順に最良のものを選びます。ピースは最小外接長方形の向きに回転し、高さの順に棚へ詰めるように並べます（First-Fit Decreasing）。

4.7 3Dの展開アニメーション

各面は、親の面と共有する辺を軸に、二つの面の法線を一致させる角度だけ回転すると親と同じ平面に開きます。この回転を元の三次元座標のまま親から子へ合成し、展開の度合い t に比例させて動かします。t = 1 ですべての面が根の面の平面にそろい、画面の展開図と同じ形になります。

4.8 未解決の問題

「すべての凸多面体は、辺に沿って切り開くだけで、重なりのない一枚の展開図にできるか」という問題は、デューラーの展開図にちなんで「デューラーの問題」と呼ばれ、1975年に G. C. Shephard が定式化して以来、今も解かれていません。Hyperfolder の展開は経験的な方法ですが、ライブラリの凸多面体はすべて一枚にまとまります。へこみのある多面体では、重なりのない辺展開そのものが存在しない場合があり、そのときは複数のピースに分けます。

5. 四次元ポリトープ4D polytopes

5.1 頂点の座標

  • 正八胞体（テッセラクト）: (±1, ±1, ±1, ±1) の16点
  • 正十六胞体: (±1, 0, 0, 0) の並べ替えの8点
  • 正二十四胞体: (±1, ±1, 0, 0) の並べ替えの24点
  • 正六百胞体: (±½, ±½, ±½, ±½)、(±1, 0, 0, 0) の並べ替え、½(±φ, ±1, ±1/φ, 0) の偶置換、の計120点（φ は黄金比）
  • 正百二十胞体: 黄金比を含む7系統の座標の計600点
  • 一様多胞体・多面体柱・デュオプリズムも、座標の並べ替えや直積で作ります。

5.2 胞の求め方

四次元の凸ポリトープでは、辺の両端の距離が最短になる点の組が辺になります（ここで扱う形はすべて辺の長さがそろっています）。各頂点 v について、隣の頂点への方向を v の反対側の超平面へ中心投影すると、三次元の「頂点図形」が得られます。その凸包の各面が、v を含む胞に対応します。胞の超平面の法線は、3本の辺ベクトルに直交するベクトル（一般化した外積）で求め、その超平面上にある頂点をすべて集めて胞とします。胞の形は、超平面内の三次元座標で凸包をとって得ます。結果は、オイラー標数 V − E + F − C = 0 で確かめています（20種すべてで成立）。

5.3 3次元への投影

シュレーゲル図
手前の胞の中心を通る軸の上、胞の超平面のすぐ外側に視点を置いて透視投影します。視点が手前の胞の超平面だけを越え、他の胞の超平面を越えない範囲（rf < d < dmax）に置くと、手前の胞が外殻になり、残りの胞がその内側をすき間なく埋める図になります。
透視投影（頂点を手前に）
頂点の方向に視点を置く透視投影です。
平行投影
第4座標を落とすだけの投影です。正八胞体を頂点から平行投影すると菱形十二面体の外形になります。

5.4 4次元回転

XW・YW・ZW の3つの平面での回転を組み合わせます。シュレーゲル図の視点は立体にごく近いため、回転すると視点が立体に入り込みます。そこで回転量に応じて、視点を外接球の外（半径の1.8倍）まで滑らかに下げます。

5.5 胞の3D展開

三次元の展開図と同じ考え方を一段上げたものです。四次元では、親と子の胞が共有する面（2次元）を固定したまま、その面に直交する2次元の平面の中で回転させます。この平面は二つの胞の法線で張られ、法線のなす角だけ回すと子の胞が親と同じ超平面に開きます。胞どうしの重なりは、三次元の分離軸定理（面の法線と、辺どうしの外積を軸にする）で判定します。正百二十胞体や正六百胞体でも、重なりのない一つながりの展開図が得られます。展開の途中は、透視投影から平行投影へ滑らかに切り替えて、開ききったときに胞の本来の形が見えるようにしています。

5.6 模型

  • 投影した胞（立体パズル） — 透視投影は平面を平面に、凸を凸に写すので、シュレーゲル図の各胞は凸多面体になります。手前の胞を外殻として、残りの胞を合同類ごとにまとめた型紙を作ります。
  • 投影の外形 — 投影した頂点全体の凸包です。
  • 胞の実形 — 本来の形の胞を、種類ごとに必要な数だけ作る型紙です。
  • 棒模型の部材表 — 投影図の辺を0.1 mm 単位で長さ別にまとめ、節点に集まる部材の数とともに表にします。

6. 表示と操作Display and interaction

  • 面は折り畳みアニメーションのため面ごとに頂点を持ち、辺と頂点は円柱と球をインスタンス描画で並べます。裏面は紙の色で描き、展開の途中で裏側が見えるようにしています。
  • 回転はドラッグの速さを角速度として保持し、手を離した後も減衰しながら回り続けます。
  • デモ・モードは、シーンの読み込み・回転・展開を順に実行する小さな台本で動いています。
  • スマホでは、各設定ブロックを操作パネルのタブへ移し、スライダーをステッパーに置き換えます。パソコン表示に戻すと元の位置に戻ります。
